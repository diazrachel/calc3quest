# Calc 3 Quest

Gamified Test 2 prep for MAC 2313 (Stewart 12.6, 14.1–14.7, 15.1–15.3).

## Deploy to GitHub Pages
1. Make a new public repo on GitHub (e.g. `calc3-quest`).
2. Upload every file in this folder, keeping the structure (`index.html` at the root, `levels/` folder below it).
3. In the repo, go to **Settings → Pages**, set Source to **Deploy from a branch**, pick `main` and `/ (root)`, Save.
4. Wait ~1 minute, then open `https://<your-username>.github.io/calc3-quest/`.

That's it — the whole site is static HTML + JS, no build step.
